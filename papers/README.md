# Scientific Papers and Reference Literature Repository

This directory contains the archival open-access PDFs, pre-prints, and reference documentation for the works cited in the Master's Thesis:

> **Thesis Title:** *Quantum Bayesian Inference for Atmospheric Biosignature and Technosignature Characterization in Exoplanetary Systems*  
> **Author:** Daniel Rivero Losa  
> **Institution:** Universidad Antonio de Nebrija (2025/2026)
